# Contributing

Use Node.js 22.14 or later. No npm install is needed. Run `npm test` before submitting a change. Add a failing behavioral test for a bug fix. Keep examples synthetic and do not commit personal notes, databases, model credentials or local paths. Model adapter tests use an injected fake HTTP response so CI stays offline.

This project was initially implemented with AI assistance. Review and understand changes before claiming authorship or production readiness.
